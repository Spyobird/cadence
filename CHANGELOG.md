# Changelog

What changed in Cadence on the phone. The format follows [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Cadence installs from its permanent address, `spyobird.github.io/cadence/`, with the day-ring icon.
- The status bar matches the page, in light and dark.
- Cadence updates itself when it's reopened, without deleting the icon.
- A red warning when Cadence is opened in a Safari tab instead of from the Home Screen.
- Cadence asks the iPhone to keep its storage every time it opens from the Home Screen.
- The build number shows, so it's clear which build is running.

### Removed

- The first version of the app. Its data isn't carried over.
